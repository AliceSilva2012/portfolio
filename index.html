Sobre mim

Olá! Meu nome é Alice Silva Pereira. Sou estudante de desenvolvimento de software focada no ecossistema JavaScript. Construo interfaces modernas e dinâmicas no Front-End, além de explorar a criação de APIs, aplicações CLI via linha de comando em Node.js e esteiras de testes automatizados.

Minha Jornada

Minha trajetória começou com a construção de sites focados em HTML semântico, CSS e manipulação de DOM. Conforme avancei nos estudos, passei a conectar minhas aplicações a APIs externas (como a iTunes Search API e OpenWeatherMap) e a integrar modelos de Inteligência Artificial via Groq API.

Hoje, estou expandindo meus conhecimentos em Back-End com Node.js, aplicando Orientação a Objetos e estruturando pipelines de CI/CD via GitHub Actions para garantir a qualidade, versionamento e execução automatizada dos meus testes de código.
